# 墨蓝陪诊 · 医疗陪诊预约与检查陪同交接平台（演示）

管理患者匿名档案、检查预约、陪诊员、服务时段、授权事项、院内路线、交接记录与服务评价。
**零第三方依赖**：仅用 Python 3.11 标准库（`http.server` + `sqlite3`），前端为原生 HTML/CSS/JS。
页面中所有姓名、证件、联系方式、检查报告均为**演示数据**，并在界面明确标注。

## 单条本地启动命令

```bash
bash run.sh
```

该命令会：建库建表 → 幂等写入演示样例（预约、临时改期、两次交接、异常、评价）→
启动服务，默认地址 <http://127.0.0.1:8000>（`ESCORT_PORT=8080 bash run.sh` 可换端口）。
启动带 `--fail-sms 2`：进程内短信通道前两次发送失败、第三次成功，用于现场演示**通知重试**。

重置演示数据：`rm -rf data/` 后重新 `bash run.sh`。

## 页面与角色

顶栏可切换三种身份（演示用，无真实登录）：

- **预约日历**：月历按日聚合各状态预约数量，点击日期下钻当日预约。
- **陪诊任务**：陪诊员端首屏即「当前地点 / 下一步 / 到达·候诊·检查完成·离院 签到按钮」，
  按时间线只放开下一步；下方为开放单与任务卡片，一键抢单。
- **检查时间线**：到达 → 候诊 → 检查完成 → 离院，清晰节点，记录地点、时间、操作人；异常与改期留痕附在下方。
- **授权事项**：本单授权清单（敏感事项单独标识），未授权操作点击“执行校验”会被拦截并**转人工确认**；
  附件区按最小权限展示，敏感检查结果无授权时锁定。
- **交接记录**：交出方 → 接收方、时间、地点、物料、备注全程留痕，可新增交接。
- **评价汇总**：平均分、星级分布、高频标签；已完成服务可由患者端评价。

视觉：医疗白 / 墨蓝 / 琥珀色；移动端自适应。**患者端永远不返回内部备注**；
陪诊员抢单前只能看到科室、时间、行动辅助与授权数量摘要，看不到患者身份和任何附件。

## 核心规则

| 主题 | 实现 |
| --- | --- |
| 并发抢单 | `UPDATE ... WHERE status='open' AND escort_id IS NULL` 条件更新 + `BEGIN IMMEDIATE`，同一时段仅一人成功，其余返回 409 |
| 必要字段开放 | 抢单成功写入 `escort_grants`，姓名/证件/授权明细/普通附件此后才对该陪诊员可见 |
| 授权边界 | 敏感事项（查看/代取报告、协助缴费、代取药）默认不放行；越权即挂起并生成人工审核单 |
| 签到状态机 | 严格按 arrived→waiting→exam_done→departed，不可跳步、不可重复；离院即 completed 终态 |
| 终态保护 | completed/cancelled/refused 不可再签到、交接、改期或重新接单 |
| 交接留痕 | 交接双方为必填，对象与时间不可为空 |
| 六类异常 | 临时改期（保留旧时间，新时间须更晚）、检查取消、患者拒绝陪同、路线变更（含“病区”转人工）、陪诊员迟到（分钟须>0）、资料缺失（转人工） |
| 敏感附件 | `sensitivity=sensitive` + 所需授权项；未接单不可见、越权查看转人工，协调员/本人患者可见 |
| 通知重试 | 进程内适配器，最多 3 次指数退避；耗尽置 failed 并自动开人工确认单 |
| 院内路线 | 进程内图适配器，给规范路线/电梯维保备用路线，并按当前位置提示下一步 |
| 患者隔离 | 患者身份只能读取本人预约，越权访问返回 403 |

## 测试

```bash
python3 -m unittest tests.test_platform -v
```

25 个用例覆盖：并发抢单（服务层多线程 + 真实 HTTP 12 并发）、授权边界与敏感附件、
签到状态顺序与终态、交接必填、六类异常分支、通知重试成功与耗尽转人工、患者隔离、
评价规则、种子幂等、路线适配器。

## 目录

```
app/config.py      常量与枚举
app/db.py          SQLite 连接、表结构、事务
app/adapters.py    进程内通知（重试/失败注入）与院内路线适配器
app/services.py    领域规则：抢单、授权、签到、交接、异常、附件、评价
app/serializers.py 角色视角序列化（coordinator/escort/patient）
app/server.py      零依赖 HTTP API + 静态页面
app/seed.py        幂等演示样例
web/               单页前端（六个标签页）
tests/             unittest 测试
run.sh             单条启动命令
```

HTTP 身份通过请求头传递：`X-Role: coordinator|escort|patient`，
陪诊员加 `X-Escort-Id`，患者加 `X-Patient-Id`。
