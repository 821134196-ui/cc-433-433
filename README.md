# 康柏陪诊 · 医疗陪诊预约与检查陪同交接平台（演示项目）

管理患者匿名档案、检查预约、陪诊员、服务时段、授权事项、院内路线、交接记录与服务评价。
**零第三方依赖**：仅使用 Python 3.11 标准库（`http.server` + `sqlite3`），
SQLite 保存预约/授权/交接等数据，本地目录保存附件，通知与院内路线由进程内模拟适配器完成。
患者姓名、证件号、检查结果均为虚构演示数据。

## 单条命令启动

```bash
python3 run.py
```

自动完成：初始化 `data/escort.db` 与附件目录 → 写入演示样例
（预约、临时改期、交接记录、逐步签到、敏感附件、越权转人工、通知重试）
→ 启动 Web 服务。浏览器访问 <http://127.0.0.1:8000/>。

启动时会注入“前两次发送失败”的通知渠道抖动，演示**指数退避重试**
（日志可见某条通知 `attempts=3` 才成功）。

环境变量：`ME_PORT`（默认 8000）、`ME_DATA_DIR`（默认 `./data`）、
`ME_NOTIFY_FAIL_FIRST_N`（注入失败次数）、`ME_DEMO_RETRY=0`（关闭重试演示）。

## 六个页面

右上角切换三种视角：**调度台 / 陪诊员（移动端）/ 患者端**。

| 页面 | 内容 |
| --- | --- |
| 预约日历 | 月历 + 当日预约清单，状态色区分待接单/进行中/完成/异常 |
| 陪诊任务 | 按状态筛选、接单、改期、取消、拒绝陪同、详情 |
| 检查时间线 | 到达→候诊→检查→完成→离院的**清晰节点**、院内路线版本、异常留痕 |
| 授权事项 | 每单授权范围 + 越权操作**人工确认队列**（批准即追加授权/驳回） |
| 交接记录 | 交接双方、地点、物品、患者确认、**系统留痕时间** |
| 评价汇总 | 平均分、星级分布、最新评价 |

- **陪诊员移动端首屏**：当前地点 / 下一步 / 签到按钮固定在首屏墨蓝卡片。
- **患者端**：隐藏内部备注与调度操作，只能看到本人数据，附件按最小权限展示。
- 配色：医疗白、墨蓝、琥珀色；时间线用圆点节点 + 连线表示进度。

## 关键业务规则

- **接单后可见必要字段**：未接单陪诊员看不到检查前要求、电话、授权明细、附件；
  接单后可看真实姓名/电话，证件号始终掩码。
- **逐步签到**：`claimed→arrived→waiting→in_exam→completed→discharged`，
  跳步报 409；重复签到幂等；离院/取消/拒绝为终态，**不能重新开启**、不能改期或补交接。
- **六类异常分别处理**：临时改期（中间态后回待接单、释放陪诊员、`version+1`）、
  检查取消、患者拒绝陪同、路线变更（版本化保留历史）、陪诊员迟到（通知调度台）、
  资料缺失（登记并通知跟进）。
- **授权边界**：超出授权范围的动作（代缴费用/代取药/未授权领报告等）一律 403 并
  **自动生成人工确认工单**，审核通过前不得执行；批准后追加授权。
- **敏感附件最小权限**：`dispatch / escort / patient / all` 四级可见性；
  检查结果需同时具备 `med_report` 授权；证件影像默认仅调度台。
- **并发接单**：`BEGIN IMMEDIATE` + 条件更新
  `WHERE status='scheduled' AND escort_id IS NULL`，
  同一时段并发抢单只有一人成功（另一人 409）；同一陪诊员时段重叠也会被拒绝。
- **患者隔离**：患者凭匿名编号 `P-xxxx` 只能访问本人预约与附件，跨档案 403。

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

28 个用例覆盖：**接单竞争**（线程并发 + 真实 HTTP 双请求，恰一人成功）、
**授权边界**（越权转人工/批准/驳回、附件可见性矩阵、接单前字段裁剪）、
**状态顺序**（跳步拒绝、终态不可重开、幂等签到、改期释放、交接必填留痕）、
**通知重试**（退避后成功、重试耗尽标记 failed、批量重发）、
**患者隔离**（列表/详情/附件下载/员工接口/写操作全部拦截）。

## 目录结构

```
run.py                    # 单命令入口：初始化 + 种子 + 启动
medical_escort/
  config.py               # 路径与可调参数
  db.py                   # SQLite 连接与建表
  models.py               # 状态/阶段/授权/异常常量
  service.py              # 领域服务（状态机、并发接单、授权、附件、评价、视图裁剪）
  notifications.py        # 进程内通知适配器（失败注入 + 退避重试 + 后台线程）
  routing.py              # 院内路线适配器（按行动能力/版本化变更）
  server.py               # 零依赖 HTTP + JSON API + 静态资源
  seed.py                 # 演示数据（含改期、交接、异常、敏感附件、越权工单）
  web/                    # index.html / app.js / styles.css
tests/test_platform.py    # 五类测试
data/                     # 运行后生成：escort.db + attachments/（已 gitignore）
```
